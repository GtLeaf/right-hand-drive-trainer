# right-hand-drive-trainer · 左行右舵练习游戏

> 方案日期：2026-09-26。定位：出发前在手机上练习**左侧通行的判断习惯**，不是驾驶资格培训，也不能代替当地交规和实车练习。**新西兰是默认地区**；英国（英格兰、苏格兰、威尔士）可切换，其他国家/地区不能直接套用。

## 试玩

已实现无需账号的静态网页原型。进入本目录运行 `npm run dev`，再用电脑浏览器打开 `http://localhost:5173/`；手机同一网络下可用电脑的局域网地址预览。`npm run check` 检查脚本语法，`npm test` 运行规则测试，`npm run smoke` 在开发服务器运行时执行浏览器流程检查。首次联网加载并显示「离线资源已就绪」后可在同一浏览器离线打开；**手机通过普通 HTTP 局域网地址预览时无法启用 Service Worker，手机离线使用需要部署到 HTTPS 地址**。本机进度可被浏览器清理。

当前交通与判分是教学原型，不能当作完整法规或真实驾车训练。发布前必须逐项对照目的地最新官方交规，并在手机真机上复核。

原型已包含双地区切换、六个引导关与解锁后的自由小镇、NPC 车流、转向灯、四向信号灯、违规记录和离线缓存。道路标线在路口前中止，西北与东侧 T 字口分别固定为 STOP 和 GIVE WAY；三条 NPC 路线在地图内连续闭环，信号、停车、让行、环岛与新西兰窄桥使用简化的控制点逻辑。第七关严重违规只记录和提示，不暂停操作。

手机触控界面会阻止长按选中文字及弹出复制菜单，保留首页正常滚动；左/右转向灯在车辆同侧的前后灯点闪烁，按住刹车时两侧尾灯变亮，NPC 停车或让行时也会亮尾灯。

**当前边界**：下文的关卡与交互描述保留产品规划，不代表所有细节已实现。目前没有实际行人、观察按钮、英国禁入/单行道场景、正式限速判分或精确的所有路权判断。右转对向车和玩家让行仍为距离近似；不能据此学习完整交规。首次缓存成功后的离线重开已在桌面浏览器检查，手机真机、交通法规细节及前六关每条完整人工驾驶路线仍待验证。

## 一句话玩法

前六关每局 2–4 分钟，俯视驾驶小车按路线抵达终点；第七关在小地图中不限时自由驾驶。玩家要保持左侧车道、提前判断让行、按信号灯行驶并打转向灯；结束时回放错误位置与正确做法。不是竞速游戏，安全优先于用时。

## 地区选择

- 首页先选**新西兰 🇳🇿（默认）**或**英国 🇬🇧**，游戏中随时可返回切换；关卡进度、成绩按地区分别保存，界面始终标出当前规则地区。
- 共用俯视驾驶与路口地图，但按地区加载独立的标志、路面标线、灯色、环岛转向灯提示和判分规则。切换时重开当前关，不沿用另一地区的规则或成绩；首次联网后两个地区包都缓存到本机。
- 新西兰关卡优先符合用户目的地；澳大利亚、日本等仅在逐项核对官方规则后增加，不提供含糊的“通用右舵”模式。

## 关键取舍

| 问题 | 决定 | 理由 |
| --- | --- | --- |
| 俯视还是第一人称 | **首发仅俯视**，镜头随车朝向旋转，车头保持朝屏幕上方 | 路口车道和来车方向更清楚；第一人称留待后续训练观察盲区、视线与驾驶座位置。车图标标出右侧驾驶位，但不宣称能模拟真实右舵手感。 |
| 底部方向盘还是摇杆 | **左下横向转向滑杆/摇杆**，右下「油门」「刹车」两键；松开油门自然减速 | 双拇指可操作，转向范围受限；虚拟方向盘在小屏上占地较大且需要大幅滑动。可在原型测试后再决定是否增加方向盘皮肤。 |
| 要不要转向灯 | **要**：左右灯为点按切换，转完自动回正；教学关有提示，考核关无提示 | 新西兰练习转弯前至少提前 3 秒示意，并正确示意离开环岛。点按可在减速或停车时完成，不要求第三根手指同时按住。 |
| 要不要红绿灯 | **要**：红/黄/绿、停止线与过街行人；英国包另含红黄同亮 | 英国红黄同亮仍需停车；新西兰不能直接照搬这个英国灯色阶段。绿灯也须确认路口可通行。 |

## 首发关卡（6 个教学关 + 1 个自由关）

1. **左侧起步**：从停车点出发，进入左侧车道；熟悉转向、油门、刹车与右侧驾驶位提示。
2. **T 型左转**：支路 `STOP` + 停车线（新西兰为黄线），必须停稳、观察主路后左转；注意转入左侧车道。
3. **T 型右转**：`GIVE WAY` + 让行线（新西兰为白线与三角标记），等待双向安全间隙后右转，不抢主路车辆。
4. **信号十字路口**：分别左转、右转；读停止线和灯色，绿灯右转仍要判断对向来车与行人。
5. **单车道环岛**：入口让行、顺时针绕行；新西兰包明确练习左转提前打左灯、直行接近环岛不打灯、右转提前打右灯，以及经过前一出口后打左灯离开。
6. **混合路线**：串联 T 型口、红绿灯和环岛，加入斑马线；新西兰包增加单车道桥梁的优先通行标志，英国包增加 `NO ENTRY` 禁入/单行道提示；无操作提示。
7. **自由练习小镇**：完成第六关后解锁，可反复进入。把上述地点连成可循环行驶的小型街区地图，覆盖左侧通行、T 型路口左右转、`STOP`、`GIVE WAY`、信号灯、行人过街、单车道环岛；新西兰地图包含单车道桥梁。没有固定终点或失败条件，可自由选路线、随时重来或主动查看练习记录。首次进入标出地标，熟悉后可关闭引导。

**可见信息**：道路箭头、停车线/让行线、`STOP`、`GIVE WAY`、环岛、限速、禁入、单行道、斑马线、信号灯，以及新西兰单车道桥梁的让行标志；不在首发塞入高速公路、复杂多车道环岛、超车、倒车停车。

## 手机界面与反馈

- 横屏优先：教学关上方显示下一步路线，自由关改为可收起的小地图；当前限速及速度始终可见。中央为俯视道路；下方为双拇指驾驶区，转向灯置于右手可点区域。安全区避开系统手势，按钮尺寸做真机测试。
- 教学时可点「观察」短暂停车并突出各方向来车、行人和待进入车道；考核时隐藏这些光效。允许随时暂停、重试与慢速练习。
- **前六关**：重大错误（逆行、闯红灯、未停车通过 `STOP`、抢行/碰撞）立即冻结并解释，其他错误（忘记转向灯、越线、过快）在结算中标记。成绩按安全、规则、观察三项呈现，不以秒数鼓励冒险。
- **第七关**：所有违规仅以屏幕边缘短提示和事件日志说明「发生了什么／正确做法」，不弹窗、不暂停、不强制回起点、不结束驾驶。重复同类提示短时间合并；严重碰撞也标为重大违规，但短暂解除车辆相互阻挡，确保玩家能继续操作。玩家主动点「查看本次练习」才展示错题回顾。

## NPC 交通

- 教学关与自由关都加入少量 NPC 车辆，自由关同屏先控制在 **2–4 辆**，密度可选低/标准；行人单独计数。车辆按地区规则沿固定路线行驶、打转向灯、在信号灯/路口/单车道桥梁前让行，不随机急刹或故意撞玩家。
- 用 NPC 形成 T 型路口主路来车、环岛车和桥梁对向车等练习情境。玩家及 NPC 均不会从环岛内起步；车辆按三条闭环路线驶出画面后继续运行，绕回原处，不在画面边缘重新生成。车流密度切换在重开关卡后生效，不在驾驶途中增删车辆。
- NPC 不是计时障碍：让行判断以实际车辆路径是否冲突为准；玩家有错时由提示说明优先关系。考核和自由练习使用同一套地区路权判定，区别只在是否中断操作。

## 离线与实现边界

- 采用轻量 **2D Canvas + PWA**：首次联网打开时缓存两地区关卡、规则、字体、图片和音效；显示「离线资源已就绪」后可断网切换、重玩。进度保存在设备本地，不要求账号、地图服务或云端请求。
- 首发使用少量脚本化 NPC 车辆和行人，不做开放世界或精确驾驶物理；第七关地图小而连通，以路权判断正确、操作易学为目标。
- 发版前做手机真机飞行模式测试（首次缓存完成后冷启动、切换地区、通关、重开、分区成绩保存），重点验证第七关连续练习、违规后仍可操控、NPC 无死锁，并对照目的地现行官方 Road Code、请熟悉新西兰及英国交规的驾驶者分别审阅关卡和判分。浏览器存储可被清理，因此不承诺永久存档。
- 新地区以独立**规则包**加入，分别核对标志、灯色、让行、环岛和信号习惯后再开放，不把“左侧通行”误当成全球统一交规。

## 调研依据

- 新西兰交通局 NZTA《[General Road Code](https://www.nzta.govt.nz/roadcode/general-road-code/)》：新西兰包的路口、环岛和单车道桥梁规则复核入口。
- 英国《Highway Code》[规则 160、170–183、184–190、195](https://www.gov.uk/guidance/the-highway-code/using-the-road-159-to-203)：靠左、路口让行、`STOP`/`GIVE WAY`、转弯示意、环岛及行人。
- 英国《Highway Code》[灯光信号](https://www.gov.uk/guidance/the-highway-code/light-signals-controlling-traffic)与[道路标志](https://www.gov.uk/guidance/the-highway-code/traffic-signs)：红黄同亮仍停车，黄灯原则上停车，以及首发标志范围。
- [MDN：PWA 离线运行](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation)：用 service worker 缓存资源，首次资源下载完成后支持离线访问。
